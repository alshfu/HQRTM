# Техническое задание (ТЗ) — FRONTEND
## Проект: HomeQ Real-Time Monitor (HQRTM)
### Этап 2 — веб-приложение (личный кабинет / дашборд)

> Это **второй из двух** документов проекта. Первый — `HQRTM_ToR_Backend.md`. Frontend **подключается к API**, реализованному на Этапе 1, и не дублирует серверную логику.

---

## 0. Общие положения

### 0.1 Назначение
Веб-приложение (личный кабинет/дашборд), позволяющее пользователю **без участия разработчика**: зарегистрироваться и войти, привязать Telegram, создавать и редактировать фильтры мониторинга, видеть живую ленту совпавших объявлений (real-time) и историю уведомлений, управлять аккаунтом. Этот этап реализует тот самый «kommersiellt gränssnitt», который в исходном ТЗ был вне scope первой фазы.

### 0.2 Глоссарий
| Термин | Значение |
|---|---|
| **FCFS / «Först till kvarn»** | Тип объявления «первый успел — первый получил» (целевой). |
| **Фильтр** | Набор критериев пользователя (город/район, цена, комнаты, площадь, «только FCFS»). |
| **Живая лента (feed)** | Real-time список объявлений, совпавших с фильтрами. |

### 0.3 Зависимость от Backend
Frontend потребляет API из Этапа 1. Минимальный контракт, на который он опирается:
| Метод | Endpoint | Назначение |
|---|---|---|
| POST | `/auth/register`, `/auth/login`, `/auth/refresh` | Регистрация/вход (JWT). |
| GET/POST/PUT/DELETE | `/filters` | CRUD фильтров. |
| GET | `/listings?matched=true` | Лента совпавших объявлений. |
| GET | `/notifications` | История уведомлений (пагинация). |
| POST/GET | `/telegram/link`, `/telegram/status` | Привязка и статус Telegram. |
| GET/PUT/DELETE | `/me` | Профиль и удаление аккаунта (GDPR). |
| WS | `/ws/feed` | Real-time push новых совпадений. |

### 0.4 Комплаенс (для Frontend)
- **GDPR:** экран удаления аккаунта и всех данных (right to erasure), видимые ссылки на политику конфиденциальности и условия, явное согласие при регистрации.
- Токены/сессии хранить безопасно (httpOnly cookie предпочтительно), не логировать PII в браузере.

## 2.1 Цели этапа
Дать пользователю полный самостоятельный путь:
регистрация → привязка Telegram → настройка фильтров → живая лента совпадений (real-time) → история уведомлений → управление аккаунтом.

## 2.2 Архитектура фронтенда
- **SPA** (или SSR/Next.js для SEO-лендинга + защищённый дашборд).
- Общение с backend по REST + **WebSocket** (`/ws/feed`) для real-time.
- Безопасное хранение токенов и авто-refresh JWT.

## 2.3 Карта экранов / пользовательские сценарии
1. **Landing** → регистрация/вход.
2. **Онбординг**: привязка Telegram (deep-link/код) → создание первого фильтра.
3. **Дашборд**: живая лента совпадений + быстрый доступ к фильтрам.
4. **Фильтры**: список, создание, редактирование, вкл/выкл.
5. **История уведомлений**: список с пагинацией и фильтрацией.
6. **Настройки аккаунта**: профиль, смена пароля, удаление аккаунта (GDPR).
7. *(Опционально)* **Биллинг/тариф**.
8. *(Опционально)* **Админ-панель**: пользователи, статус источника, метрики.

## 2.10 Поставки и критерии приёмки
**Поставки:**
1. Исходный код фронтенда в Git-репозитории.
2. Развёрнутое веб-приложение, подключённое к backend Этапа 1.
3. Инструкция по сборке/деплою/настройке окружения.

**Критерии приёмки:**
- Пользователь полностью проходит путь: регистрация → привязка Telegram → создание фильтра → живая лента → история.
- Real-time лента обновляется без перезагрузки, переживает разрыв соединения.
- Приложение адаптивно (desktop + mobile) и локализовано (шв./англ.).
- Реализовано удаление аккаунта/данных (GDPR).

## Риски (frontend)
| Риск | Митигация |
|---|---|
| Нестабильное WebSocket-соединение | Авто-reconnect с backoff, fallback на polling, дедуп на клиенте. |
| Рассинхрон контракта с backend | Общие типы/OpenAPI-клиент, контрактные тесты. |
| GDPR-несоответствие в UI | Экран удаления данных, согласия, ссылки на политику. |
| Деградация при большом объёме ленты | Виртуализация списка, пагинация. |

## Definition of Done (frontend)
- Критерии приёмки выполнены; CI зелёный (линт + тесты).
- E2E-сценарий проходит стабильно.
- Адаптивность и локализация проверены на desktop и mobile.
- Приложение задеплоено и подключено к продакшн-API.
