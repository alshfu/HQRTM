Vad ingår i releasen Flask · MongoDB · SSE · asyncio-poller

Källadaptrar live

Isolerade adaptrar HomeQ · Qasa · Samtrygg i en gemensam modell listings; unik nyckel = paret (source, external_id). Ny plattform = ny adapter, kärnan ändras inte. Aktiveras efter ToS-kontroll.

FCFS-detektion live

Känner igen «Först till kvarn» och sållar bort köbaserade annonser (köpoäng/queue). Dedup via TTL-index utan Redis. Latensbudget — mål ≤ 1,5 s.

Matchning mot filter live

Matchar nya FCFS mot användarens filter (hyra/rum/yta/område) och köar aviseringar idempotent — inga dubbletter vid omstart.

Realtidsflöde live

SSE + MongoDB Change Streams: nya träffar når panelen direkt, med auto-reconnect och fallback till polling.

API + autentisering live

REST API på Flask: JWT (Argon2), CRUD för filter, GDPR-radering (DELETE /api/me), OpenAPI + Swagger UI. Rate-limit på känsliga endpoints.

Webbpanel + i18n live

Jinja2 + production-Tailwind + Vanilla JS: flöde, filter, aviseringar, inställningar. Gränssnittet på svenska (sv/en), roll user/admin och adminpanel.

Telegram-leverans Fas 3

Kontokoppling är klar; leverans av aviseringar med länk i Telegram (aiogram) är på väg. Just nu syns träffar redan i webbflödet.

Efterlevnad & etisk last live

En central poller, jitter och backoff, respekt för 429/Retry-After. Officiellt API först; en adapter aktiveras bara efter positivt ToS-besked.
