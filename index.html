HQRTM — живой мониторинг аренды жилья

Круглосуточно отслеживает публикации на шведских площадках, мгновенно выделяет объявления «Först till kvarn» (FCFS), сопоставляет с фильтрами пользователя и доставляет уведомление со ссылкой. Один поллер, мульти-source адаптеры, real-time лента.

Что в релизе Flask · MongoDB · SSE · asyncio-поллер

Мульти-source адаптеры live

Изолированные адаптеры HomeQ · Qasa · Samtrygg в единой модели listings; уникум — пара (source, external_id). Новая площадка = новый адаптер, ядро не меняется. Включение — после проверки ToS.

FCFS-детекция live

Распознаёт «Först till kvarn» и отсеивает «очередные» (köpoäng/queue). Дедуп через TTL-индекс без Redis. Бюджет латентности — цель ≤ 1.5 с.

Матчинг с фильтрами live

Совпадение новых FCFS с фильтрами пользователя (цена/комнаты/площадь/район) и идемпотентная постановка уведомлений — без дублей при перезапуске.

Real-time лента live

SSE + MongoDB Change Streams: новые совпадения прилетают в кабинет мгновенно, с авто-reconnect и fallback на polling.

API + аутентификация live

REST API на Flask: JWT (Argon2), CRUD фильтров, GDPR-удаление (DELETE /api/me), OpenAPI + Swagger UI. Rate-limit на чувствительных эндпоинтах.

Веб-кабинет + i18n live

Jinja2 + production Tailwind + Vanilla JS: лента, фильтры, уведомления, настройки. Интерфейс по-шведски (sv/en), роль user/admin и админ-панель.

Telegram-доставка Фаза 3

Привязка аккаунта реализована; доставка уведомлений со ссылкой в Telegram (aiogram) — на подходе. Сейчас совпадения уже оживляют веб-ленту.

Комплаенс & этичная нагрузка live

Один центральный поллер, джиттер и backoff, уважение 429/Retry-After. Официальное API в приоритете; адаптер включается только после положительного вывода по ToS.
