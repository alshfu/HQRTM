Источники: `docs-core.homeq.se`, `api.homeq.se/api-docs/`, robots.txt площадок, SwaggerHub.

**Принципы (по ТЗ):**
- Официальное API — в приоритете. Скрейпинг — только fallback и только если не противоречит ToS.
- Один **центральный** поллер на всех пользователей (не N персональных ботов) — снижает нагрузку на источник.
- Разумные интервалы, джиттер, экспоненциальный backoff, уважение `429/503/Retry-After`, ротация User-Agent.

## 2. GDPR (ЕС)

Храним персональные данные: e-mail, Telegram chat_id, фильтры пользователя.

- [ ] **Правовое основание** обработки (согласие пользователя при регистрации).
- [ ] **Политика конфиденциальности** — текст + ссылка в UI.
- [ ] **Право на удаление** (right to erasure): `DELETE /api/me` удаляет аккаунт и все связанные данные.
- [ ] **Журнал согласий** (`users.consent_at`).
- [ ] **Шифрование секретов**, пароли — только хэш (Argon2). Без PII в логах.
- [ ] (Опц.) География хостинга данных (ЕС-резидентность).

- Бот **не** подаёт заявки на жильё автоматически.
